# Reflexive Agent Scaffold

## Purpose

This example demonstrates how the reflexive architecture described in the [root README.md](../../README.md) can be instantiated at the prompt engineering level. It provides a modular master prompt designed to create a reflexive agent loop that embodies the architectural principles in miniature.

## Architecture Alignment

This scaffold reflects the core components of the context-adaptive architecture:

- **Capability-awareness**: The agent explicitly articulates its own capabilities and limitations
- **Checkpoint system**: Built-in progress tracking and verification points
- **Intentional friction**: Deliberate pause points for user consent and reflection
- **Consent-diff-update loop**: Mirrors the full system's feedback and evolution cycle
- **Reflexive Agent Hub**: Demonstrates self-monitoring and adaptive behavior patterns
- **Diff & Consent UI**: Implements user confirmation and iterative refinement workflows

## Design Principles

While this is implemented as a single prompt, it reflects the architecture's key design principles:

1. **Context-adaptive behavior**: Responds to user needs and environmental changes
2. **Transparent evolution**: Makes its reasoning and adaptation process visible
3. **Human-centered growth**: Prioritizes user development over pure automation
4. **Intentional friction**: Includes deliberate checkpoints for reflection and consent

## Usage

This scaffold can be used as:
- A standalone reflexive agent prompt
- A component in broader agent orchestration setups
- A template for implementing reflexive patterns in other AI systems
- A practical demonstration of vibe architecting principles

## Connection to Full Architecture

This example specifically demonstrates how the **Reflexive Agent Hub** and **Diff & Consent UI** components from the main architecture can work together in a simplified form. The prompt implements the core feedback loop that enables systems to evolve with their users rather than simply executing predefined tasks.
